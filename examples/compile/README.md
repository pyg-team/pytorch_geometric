# `torch.compile` Examples

This directory contains examples demonstrating the use of `torch.compile` in different GNN models.

| Example                | Description                                                       |
| ---------------------- | ----------------------------------------------------------------- |
| [`gcn.py`](./gcn.py)   | `torch.compile` in `GCN`                                          |
| [`gat.py`](./gat.py)   | `torch.compile` in `GAT`                                          |
| [`gin.py`](./gin.py)   | `torch.compile` in `GIN`                                          |
| [`film.py`](./film.py) | `torch.compile` in [`GNN-FiLM`](https://arxiv.org/abs/1906.12192) |
